# nodejsMC
node js API multicontainer

### Summary of Tools and Systems Used
WSL Ubuntu:
For running Linux commands, Docker, Kubernetes, Terraform, Ansible, and Node.js.

Docker Desktop:
For managing Docker containers and enabling WSL 2 integration.

Minikube:
For running a local Kubernetes cluster.

Terraform:
For provisioning the remote server.

Ansible:
For configuring the remote server.

GitHub Actions:
For setting up the CI/CD pipeline.

Postman or curl:
For testing the API endpoints.

Git:
For version control and pushing code to GitHub.
